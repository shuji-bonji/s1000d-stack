# UC06 — DML と CSDB を突き合わせる

## 依頼文

> プロジェクトの DML（`fixtures/incoming/dml/DML-KENBAIKI-K0001-S-2026-00001_001-00.XML`）と `csdb/` を突き合わせて、次を一覧にしてください。
>
> - DML に載っているのに CSDB に無いもの
> - CSDB にあるのに DML に載っていないもの
> - 両方にあるが版が食い違うもの

## 入力

- `fixtures/incoming/dml/DML-KENBAIKI-K0001-S-2026-00001_001-00.XML`（自作の DML）
- `csdb/`（UC02〜UC05 で書いたものを含む）

## 手順

1. DML に載っている DMC と版を表にする（DML の XML を自分で解析せず、ツールの応答から書く）。
2. DML と `csdb/` を突き合わせ、上の 3 つの一覧と、それぞれの件数を書く。
3. 別の方法（CSDB の一覧を DML 付きで取るなど）でも同じ突き合わせを行い、手順 2 と件数が同じかを書く。
4. 食い違いの原因を、採番の違い（UC02・UC04 で決めた DMC と DML の DMC が違う）と、DM の欠陥とに分けて書く。

## 記録すること

- 手順 2 と手順 3 で使ったツール
- 件数が違った場合、その差と、応答のどの項目から分かったか
