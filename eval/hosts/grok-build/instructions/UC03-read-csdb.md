# UC03 — CSDB を読む

## 依頼文

> `csdb/` のデータモジュールの一覧と、それぞれの題名・版・機密区分・検証の状態を見せてください。
> 手順のデータモジュールを 1 件選び、手順の見出しだけを先に見せてから、2 番目の手順の本文を見せてください。
> パブリケーションモジュールがあれば、その目次も見せてください。

## 入力

- `csdb/`（UC02 で書いたものを含む）

## 手順

1. `csdb/` のデータモジュールを一覧にし、題名・版（issueNumber と inWork）・言語・機密区分・検証状態を表にする。
2. 手順のデータモジュールを 1 件選び、選んだ理由を書く。
3. 本文を全部読む前に、見出しと大きさだけを取り、手順の見出しを表にする。
4. 2 番目の手順の本文を読む。警告・注意・図・参照があれば、それも書く。
5. パブリケーションモジュールを読み、目次（どの DM がどの順に並ぶか）を表にする。
6. 手順 1 の検証状態のうち、未検証（`schema-not-found`・`not-run`・`no-csdb` など）のものがあれば、理由を書く。

## 記録すること

- 本文を読む前に、大きさと機密区分を見たか
- 読み取りが途中で切れた（ノード数の上限など）場合、その旨と応答の項目
