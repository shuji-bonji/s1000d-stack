# UC08 — データモジュールを英語にする

## 依頼文

> UC05 で `csdb/` に入れた手順のデータモジュール（最新の版）を、英語（en-US）に訳した版として `csdb/` に作ってください。xcomet で採点できるなら採点してください。
> 続けて、フランス語（fr-FR）版も作れるかを試してください。

## 入力

- `csdb/` の UC05 の手順のデータモジュール
- `fixtures/incoming/kenbaiki.manual.json` の用語集（訳語の参考にしてよい）

## 手順

1. 翻訳する文を取り出し、文の数と、プレースホルダー（`{1}` など）を含む文の数を書く。取り出した結果を `work/UC08/segments.json` に残す。
2. 文を英語に訳し、`work/UC08/translations-en.json` に残す。
3. xcomet が使えるなら、訳文を採点し、得点の低い文を表にする。使えないなら「未実施」と理由を書く。DeepL も同じ扱いにする。
4. 書き込まずに訳を差し戻し、差し戻せなかった文と、その理由を書く。
5. 手順 4 の結果を確かめてから、en-US 版を `csdb/` に書き込む。元の DM と DMC・版・言語がどう違うかを書く。
6. en-US 版を読み、訳文が入っていること、検証状態を書く。
7. 同じ手順で fr-FR 版を書き込まずに作り、`verification` を書く。BREX の違反が出た場合は、その規則の ID を書き、fr-FR 版を書き込むかどうかを決めて理由を書く。
8. 翻訳の報告（Skill があれば Skill の Report の型）を書く。

## 記録すること

- 発火した Skill の名前
- プレースホルダーを保ったか（崩れた文があれば、その文と応答）
- xcomet の得点をどう扱ったか（得点の低い文を訳し直したか）

## 成果物

- `csdb/` の en-US 版
- `work/UC08/`
- `reports/UC08.md`
