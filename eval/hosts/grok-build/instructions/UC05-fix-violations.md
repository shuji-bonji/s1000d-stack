# UC05 — BREX の違反を候補から直す

## 依頼文

> UC04 で作った手順のデータモジュールについて、機密区分を `09`、責任企業コードを `K0001` にした下書きで組み立て直し、どうなるかを見せてください。
> そのあと、BREX に沿うように直して、UC04 のデータモジュールの次の版として `csdb/` に入れてください。

## 入力

- `work/UC04/draft.json`（UC04 の下書き）
- `csdb/` の UC04 のデータモジュール

## 手順

1. UC04 の下書きを複製し、機密区分を `09`、責任企業コードを `K0001` に変えて `work/UC05/draft-violating.json` に置く。
2. 書き込まずに組み立て、次の 3 つを分けて表にする: サーバーが自動で直したもの、候補付きで残った修正、候補の無い修正。それぞれの規則の ID と候補を書く。
3. 試しに、残った機密区分の修正を、候補に無い値 `05` で直すよう求め、どう返るかを記録する。
4. 候補の中から値を 1 つ選んで直し、選んだ値と理由を書く。直した後の `verification` を書く。
5. UC04 のデータモジュールの次の版として `csdb/` に書き込む。書き込みでエラーが返ったら、その内容を記録し、どう対処したかを書く。
6. `csdb/` に、UC04 の版と UC05 の版の両方があるか、どちらか一方だけかを書き、そうなった理由を書く。

## 記録すること

- 手順 2 の「自動で直したもの」に気づいた経緯（応答のどの項目を見たか）
- 手順 3 の応答（拒まれた理由のコード）
- 版をどう決めたか

## 成果物

- `csdb/` の UC04 の次の版
- `work/UC05/`
- `reports/UC05.md`
