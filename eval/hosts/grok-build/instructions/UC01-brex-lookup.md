# UC01 — BREX の決まりを調べる

## 依頼文

> S1000D の配布物に入っている既定の BREX には、どんな決まりがありますか。データモジュールの機密区分（securityClassification）について決まりがあれば教えてください。
> 続けて、このプロジェクトの BREX（`csdb/` にある KENBAIKI のもの）では、機密区分にどの値を使えるかを教えてください。

## 入力

- S1000D の配布物（設定ファイルの `specDir`）
- `csdb/DMC-KENBAIKI-A-00-00-00-00A-022A-D_001-00_JA-JP.XML`（プロジェクトの BREX。自作）
- `csdb/DMC-KBWORKS-A-00-00-00-00A-022A-D_003-00_JA-JP.XML`（組織の BREX。自作）

## 手順

1. 既定の BREX を特定し、その DMC（またはファイル名）と、ルールの数を書く。
2. 既定の BREX に、機密区分に関するルールがあるかを調べる。あれば、ルールの ID・対象（どの要素・属性か）・許可する値を書く。無ければ「無い」と書き、どう確かめたかを書く。
3. プロジェクトの BREX から始まる BREX の連鎖（どの BREX がどの BREX を指しているか）を書く。
4. プロジェクトの BREX で、機密区分に使ってよい値と、その規則の ID を書く。
5. 既定の BREX とプロジェクトの BREX で、機密区分の扱いがどう違うかを表にする。

## 記録すること

- 手順ごとに選んだツールと、選んだ理由
- BREX を指定するときに使った形（ファイルのパスか、DMC か）と、迷った箇所
- 既定の BREX の本文は写さない。規則の ID・対象・値の要約だけを書く
