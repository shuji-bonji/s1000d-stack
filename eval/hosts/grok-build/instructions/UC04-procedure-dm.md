# UC04 — 手順を手順のデータモジュールにする

## 依頼文

> 次の手順を S1000D の手順データモジュールにして、`csdb/` に入れてください。
>
> 1. 電源スイッチを切る。
> 2. 前面扉を開ける（扉は重いので注意）。
> 3. 紙幣ユニットを引き出す。
>
> 型式識別コードは `KENBAIKI`、BREX はプロジェクトの BREX（KENBAIKI）です。題名は「紙幣ユニットを取り出す」にしてください。

## 入力

- 上の依頼文の手順 3 つ
- `csdb/` の BREX 2 件

## 手順

1. このプロジェクトの BREX から、手順のデータモジュールに関係する決まり（情報コード・責任企業・機密区分など）を読む。
2. 採番（SNS・情報コード・言語・版）を決め、決めた値と理由を書く。UC02 で書いた DM と DMC が重ならないことを確かめる。
3. 下書きを作り、`work/UC04/draft.json` に残す。「扉は重いので注意」をどの形で表したかを書く。
4. 書き込まずに組み立て、`verification`・自動で直された箇所・残った修正を表にする。
5. 残った修正を片付ける。入力のエラーが返った場合は、エラーの項目を読んで下書きを直し、何を直したかを書く。
6. 手順 4〜5 の結果を確かめてから、`csdb/` に書き込む。
7. 書き込んだファイルを、組み立てたサーバーとは別のサーバーで検証し、検証状態が手順 4〜5 と同じかを確かめる。
8. 作成の報告（Skill があれば Skill の Report の型）を書く。

## 記録すること

- 発火した Skill の名前
- 下書きを作るときに読んだもの（ツールの説明、Skill の参照ファイルなど）
- 入力のエラーの回数と、直せた回数

## 成果物

- `csdb/` に書いた手順のデータモジュール
- `work/UC04/draft.json`
- `reports/UC04.md`
