`emphasisType` は、文の中の強調（`emphasis`）の種類を示す属性です。省略できます。

## 値の意味

| 値 | 意味 |
| --- | --- |
| `em01` | 太字 |
| `em02` | 斜体。過去のデータのための値です |
| `em03` | 下線。過去のデータのための値です |
| `em04` | 上線。ベクトルを示すときだけ使います |
| `em05` | 取り消し線。削除した文を示す用途には使いません |
| `em51`〜`em99` | プロジェクトが意味を決める値です |

## このスタックでは

| 操作 | ツール |
| --- | --- |
| 新しく作る | {{tool:writer/build_data_module}} の下書きには、強調を書く入口がありません |
| 翻訳する | {{tool:writer/extract_segments}} は、文の中の `emphasis` を `{1}`・`{2}` の記号に置き換えて取り出します。{{tool:writer/apply_segments}} は、訳した文に元の要素を戻します |
| 値が許可されているかを確かめる | {{tool:brex/lookup_value}} |
