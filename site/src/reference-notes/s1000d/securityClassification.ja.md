`securityClassification` は、機密区分を示す属性です。データモジュール全体の機密区分は、識別・状態部の `security` 要素に書きます。本文の要素にも付けられます。

## 値の意味

値の意味は、プロジェクトが決めます。既定 BREX は `01`〜`09` と範囲 `51~99` を許可していますが、値の意味は書いていません。データ辞書にも、値の意味はありません。どの値がどの区分を表すかは、プロジェクトのビジネスルールで確かめてください。

## このスタックでは

| 操作 | ツール |
| --- | --- |
| 読む | {{tool:reader/read_data_module}}。識別・状態部（`identAndStatus`）に入ります |
| 新しく作るときに書く | {{tool:writer/build_data_module}} の `draft.securityClassification`。省略できません。ツールは値を補わず、渡された値をそのまま書きます |
| 値と意味を確かめる | {{tool:brex/lookup_value}}。プロジェクトの BREX に値の意味が書いてあれば、それを返します |

プロジェクトの BREX にも意味が書かれていない値については、どのツールも意味を返せません。
