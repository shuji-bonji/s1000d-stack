`listItemPrefix` は、順序の無いリスト（`randomList` など）の項目の前に付ける記号を示す属性です。省略できます。

## 値の意味

| 値 | 意味 |
| --- | --- |
| `pf01` | 記号を付けず、字下げだけにします |
| `pf02` | リストの階層に応じた記号を付けます |
| `pf03` | 短いダッシュ |
| `pf04` | 丸の中に点がある記号 |
| `pf05` | 白い丸 |
| `pf06` | 白い四角 |
| `pf07` | ビュレット（項目の先頭に置く丸） |
| `pf51`〜`pf99` | プロジェクトが意味を決める値です |

## 関連する決まり

- フロントマターの表題ページにある `reducedRandomList` は、`listItemPrefix` を `pf03` にします。ほかの属性は使いません（既定 BREX の BREX-S1-00117）。

## このスタックでは

| 操作 | ツール |
| --- | --- |

| 値が許可されているかを確かめる | {{tool:brex/lookup_value}} |
